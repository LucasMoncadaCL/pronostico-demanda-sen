# src/

Este directorio contiene implementaciones del benchmark, candidatos y procedimientos de auditoría desarrollados para el estudio.

Los scripts científicos se publican para inspección metodológica. Algunos scripts de evaluación y visualización necesitan archivos originales o artefactos numéricos archivados en el entorno privado; esos archivos no forman parte de esta distribución, por lo que no todos los scripts se pueden ejecutar de extremo a extremo aquí.

Las comprobaciones públicas ejecutan pruebas con datos sintéticos y verifican que el árbol de Git no incorpore archivos en formatos o rutas reservados para datos originales. No vuelven a calcular las métricas históricas de 2024–2025.
