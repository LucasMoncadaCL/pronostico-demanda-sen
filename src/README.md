# src/

En `src/` organicé las implementaciones del benchmark, los modelos candidatos y los procedimientos de auditoría que desarrollé para el estudio.

Los scripts científicos están disponibles para inspeccionar el método. Algunos de evaluación y visualización necesitan archivos originales o resultados archivados en el entorno privado, que no incluí en esta distribución; por eso no todos pueden ejecutarse de extremo a extremo desde aquí.

Las comprobaciones públicas ejecutan pruebas con datos sintéticos y verifican que el árbol de Git no incluya formatos o rutas reservados para datos originales. No recalculan las métricas históricas de 2024–2025.
