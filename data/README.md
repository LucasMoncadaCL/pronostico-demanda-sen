# Datos de la distribución pública

Esta copia no incluye observaciones del CEN, respuestas de API, archivos Excel, predicciones emparejadas con valores observados, errores que permitan reconstruirlos ni gráficos de perfiles reales.

El protocolo usa una tabla de feriados nacionales de 2025, con fuentes oficiales atribuidas en el JSON. La tabla contiene fechas y nombres; no es una serie de demanda ni un resultado del CEN.

El dashboard genera ejemplos sintéticos de forma determinista en memoria. Los módulos científicos se incluyen para inspección y pruebas con entradas de ejemplo; para reproducir numéricamente el estudio completo se necesitan datos históricos que no se distribuyen aquí.

Conservo las series oficiales y los artefactos científicos completos en un archivo privado. La investigación utilizó el producto [Demanda Real del CEN](https://www.coordinador.cl/operacion/graficos/operacion-real/demanda-real/) y revisó sus [términos de uso](https://www.coordinador.cl/terminos-y-condiciones/) y la [documentación SIP](https://portal.api.coordinador.cl/documentacion?service=sipubv2). En los términos consultados encontré que el sitio permite descargas para uso personal o académico y exige citar la fuente; prohíbe la distribución comercial sin autorización, pero no resuelve expresamente la redistribución pública no comercial de respuestas de API. No afirmo que el producto tenga una licencia abierta.

El README y el caso de estudio muestran resultados estadísticos agregados, atribuidos al CEN como fuente de observaciones. No están cubiertos por MIT o CC BY como si fueran datos propios. No he confirmado con el CEN las condiciones de reutilización de estos resultados derivados. Las licencias del código y la documentación no amplían los derechos sobre materiales del CEN.
