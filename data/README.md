# Datos de la distribución pública

Esta versión no incluye observaciones del CEN, respuestas de API, archivos Excel, predicciones emparejadas con valores observados, errores que permitan reconstruirlos ni gráficos de perfiles reales.

Se incluye una tabla de fechas de feriados nacionales 2025 utilizada por el protocolo. Sus fuentes oficiales están atribuidas dentro del JSON. La tabla contiene fechas y nombres de feriados; no es una serie de demanda ni un resultado del CEN.

El dashboard genera ejemplos sintéticos de forma determinista en memoria. Los módulos científicos se conservan para inspección y pruebas con entradas de ejemplo; la reproducción numérica completa requiere datos históricos que no se distribuyen en esta copia.

Las series oficiales y los artefactos científicos completos permanecen en un archivo privado. La fuente fue el producto [Demanda Real del CEN](https://www.coordinador.cl/operacion/graficos/operacion-real/demanda-real/); también se revisaron sus [términos de uso](https://www.coordinador.cl/terminos-y-condiciones/) y la [documentación SIP](https://portal.api.coordinador.cl/documentacion?service=sipubv2). Los términos del sitio permiten descargas para uso personal o académico y exigen citar la fuente; prohíben distribución comercial sin autorización, pero no resuelven expresamente la redistribución pública no comercial de respuestas de API. No se afirma que el producto tenga una licencia abierta.

El README incluye únicamente resultados estadísticos agregados del estudio, atribuidos al CEN como fuente de observaciones; no se ofrecen bajo las licencias MIT o CC BY como si fueran datos propios. Si se requiere certeza de reutilización de esos resultados derivados, corresponde confirmarlo con el CEN. Las licencias del código y la documentación no otorgan derechos adicionales sobre materiales del CEN.
